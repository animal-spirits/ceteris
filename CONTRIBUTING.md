# Contributing

Issues and problem reports are welcome. Pull requests from outside contributors are merged only
after the contributor agrees to the [CLA](CLA.md) by writing the sentence for the individual or
the corporate form in the pull request. The CLA lets the owner offer commercial licences
alongside AGPL-3.0-or-later (RFC 0343, RFC 0344).

Before opening a pull request, run the checks in `CLAUDE.md` (fmt, clippy, tests, `ceteris-rows
check`). Commits use conventional prefixes. A change to the design or to an accepted decision
starts as an RFC in `rfcs/`.
