Ceteris Modular

A generative patch for the score of a run. Three slow controls from the game (mood, tension, era) steer stochastic processes, and those processes play a modular synth: drifting voltages, self-exciting jumps, a Markov chain over sections, and a Turing-machine register. Same seed, same music.

dX = θ(μ − X)dt + σ dW, with μ set by the section and σ by tension. Jumps arrive as a self-exciting process: each one raises the chance of the next, so crises cluster.

A 16-bit shift register loops a melody; each clock, one bit may flip. Low tension locks the loop, high tension lets it mutate. Read through a scale quantizer.

Rows are modulation sources, columns are destinations. Each lit cell is a real cable: a gain node from the source into the destination's audio parameter, so the LFO and the third oscillator modulate at audio rate. Click a cell to cycle its depth (0, +¼, +½, +1, −½).

    Engine: Web Audio in this mock; the game build would run the same patch in fundsp (ADR 0137). Effects: ping-pong dub delay with filtered feedback, seeded convolution reverb, pad chorus, wavefolder, sidechain ducking and a bus compressor. All randomness comes from a counter-based hash of the seed, the stream and the step, so the score does not depend on timing or frame rate.
