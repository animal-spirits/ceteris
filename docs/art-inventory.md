# Art inventory

Every visual and audio asset the 1.0 app needs or should have, with a placeholder where one can be generated. Derived from ADR 0137 (art direction), 0140 to 0144 (chrome, flavour, flags, names), 0215/0216 (first run, platforms), the pre-1.0 polish plan (2026-11-09), the UI schedule (2026-11-10) and `app/` as of this commit. Sizes and counts are estimates unless marked.

Status: `exists` in the repo; `mock` placeholder generated in `app/assets/placeholder/` (`scripts/gen_placeholder_art.py`, deterministic, not wired into app code); `pipeline` produced by code or the pack build, no hand art; `artist` needs a human; `source` take from a licensed public source; `deferred` outside 1.0.

Licence rule: nothing is bundled until its licence is recorded (ADR 0005, `crates/ceteris-pack/config/sources.toml` for data, `app/ui/fonts/README.md` style table for bundled files). Placeholders are generated by us and carry no third-party licence.

## Decisions for Antonio

1. App name/mark: the icon, wordmark and capsule all wait on a fixed mark. Mock uses a graticule globe with edit-magenta and fork-violet arcs only to occupy the slot.
2. Who produces final art: commission an illustrator/designer for icon, wordmark, scenario covers, and about 10 UI sounds, or generate in-house where the style is flat vector. Panels and charts need no art by ADR 0137.
3. Noto subsetting: ship a few MB of Noto for CJK/Arabic/Indic in the app, or fetch fonts on first run like the packs.
4. Emblem coverage: ADR 0141 flags emblems as the slowest sourcing item; confirm the 1.0 target (seat countries only, or all).

## Regenerating placeholders

```
python3 scripts/gen_placeholder_art.py
```

Writes `app/assets/placeholder/` (SVG, plus two PNG tiles). Output is byte-identical across runs.
